# קו AI

קו טלפון חכם בעברית: מתקשרים לימות המשיח, שואלים בקול, ו-Gemini עונה בקול.
תומך בחיפוש באינטרנט (Groq), בהיסטוריית שיחות, ובמעבר אוטומטי בין מודלים כשהמכסה נגמרת.

## התקנה בקצרה

1. מעלים את הקבצים ל-GitHub (בלי קבצי `.env`).
2. ב-Render: New, Blueprint, בוחרים את הריפו.
3. ממלאים את המשתנים לפי `.env.example` (Environment, Add from .env).
4. בימות המשיח יוצרים שלוחה רגילה (תיקייה) במספר `1`, שם נשמרים ההקלטות והתשובות.
5. יוצרים שלוחה במספר `5`. ב"מערכת תוכן", לשונית "הגדרות מתקדמות", בוחרים `ext.ini` ומדביקים (סוג API בתפריט של ימות לא תמיד עובד, ולכן מחברים כך):

```
type=api
api_link=https://<השירות שלך>.onrender.com/yemot
```

6. אותו דבר לשלוחה `9` (היסטוריה) עם הכתובת `https://<השירות שלך>.onrender.com/history`.
7. מתקשרים ובוחרים את שלוחה 5.

המדריך המלא למתחילים מצורף בנפרד.

## שאלה בהקלדה או בהקלטה

הפתיח אומר: "שלום וברכה, להקלטת שאלה הקש 1 להקלדה הקש 2". אפשר לשנות אותו בשדה `g` של השלוחה (`EXTENSIONS`) או במשתנה `GREETING`. אם קיים קובץ `greet.wav` בשלוחה, הוא מושמע במקום הפתיח ואחריו התפריט.

- **1, הקלטה:** שומעים "דבר אחרי הצליל" וצליל, אומרים את השאלה ומקישים `#` בסיום.
- **2, הקלדה:** מקלידים את כל השאלה ברצף, ומקישים `#` בסיום.

בזמן ההמתנה לתשובה המתקשר שומע "חכה שנייה", ואם המודל מחפש באינטרנט, "חכה שנייה מחפש באינטרנט".

**עצירת תשובה:** הקשה על מקש כלשהו באמצע התשובה עוצרת אותה. הקשה על `1` עוברת ישר להקלטה, על `2` ישר להקלדה, ועל כל מקש אחר נפתח התפריט. ההמשך נשאר באותה שיחה, והמודל יודע שהתשובה נקטעה.

האותיות מוקלדות כמו בטלפון מקשים ישן: מקישים על המקש כמספר מקומה של האות עליו.

| מקשים | אותיות |
|---|---|
| `3` | א ב ג |
| `2` | ד ה ו |
| `6` | ז ח ט |
| `5` | י כ ל |
| `4` | מ נ |
| `9` | ס ע פ |
| `8` | צ ק |
| `7` | ר ש ת |

לדוגמה `7` = ר, `77` = ש, `777` = ת. בין שתי אותיות על אותו מקש מקישים `1` (למשל `3 1 3` = אא). מקשים אחרים מתחילים אות חדשה לבד.

| מקשים | פעולה |
|---|---|
| `0` | רווח |
| `00` | מחיקת התו האחרון |
| `11` | הספרה 1 |
| חמש הקשות על מקש | הספרה של המקש (`44444` = 4) |
| `#` | סיום ושליחה |

אותיות סופיות (ך ם ן ף ץ) מתווספות אוטומטית בסוף מילה. זמן ההמתנה למקש הבא בהקלדה הוא `KBD_WAIT` שניות (ברירת מחדל 20).

## תשובות ארוכות ומפורטות

התשובות ארוכות ומפורטות, בסגנון שיחה. האורך נקבע ב-`MAX_WORDS` (ברירת מחדל 700, לא פחות מ-500 ולא יותר מ-1000). תשובה ארוכה מוקראת בחלקים במקביל ומחוברת לקובץ אחד. אם התשובות נקטעות או מאחרות, אפשר להגדיל את `TURN_BUDGET_MS`.

## היסטוריה בקול רובוטי

כל שאלה ותשובה נשמרות בשלוחת ההיסטוריה כקובץ טקסט, גם שאלות שהוקלטו (ג׳מיני מתמלל אותן תוך כדי התשובה). בשלוחת ההיסטוריה הכול מושמע בקול הרובוטי של ימות, גם השאלות וגם התשובות, ואפשר להמשיך שיחה, למחוק אותה ולתת לה שם. שיחות ישנות שנשמרו כהקלטות עדיין מושמעות כמו קודם. הבדיקה `/selftest` מוודאת שהשמירה כטקסט עובדת בחשבון שלכם.

## תקיית שירים (מוזיקה בזמן ההמתנה, לא חובה)

משליחת השאלה ועד שהתשובה מוכנה המתקשר שומע שירים מתקיית השירים. ימות לא יכולה להפסיק קובץ באמצע השמעה, ולכן כל שיר נחתך לחלקים קצרים (`SONG_SEG_SEC`, ברירת מחדל 5 שניות). השרת משמיע כמה חלקים (`HOLD_CHAIN`, ברירת מחדל 2), בודק אם התשובה מוכנה וממשיך מהמקום שבו עצר. אם אין שירים, המערכת ממתינה בשקט כמו קודם.

הגדרה:

1. פותחים בימות שלוחה חדשה (תיקייה רגילה, לא API) ורושמים את מספרה במשתנה `SONGS_EXT`, למשל `8`.
2. קובעים סיסמה במשתנה `SONGS_PASS`.
3. מוסיפים שירים באחת משתי דרכים:
   - **הדף `/songs`** בכתובת השירות: מזינים סיסמה, בוחרים קובץ שמע או וידאו ומעלים. אם מזינים מספר טלפון, השיר אישי ומושמע רק למתקשר הזה. בלי מספר, השיר משותף לכולם. מתקשר שיש לו שירים אישיים שומע רק אותם. בדף אפשר גם לראות ולמחוק שירים.
   - **קובץ ישירות לתקייה** (דרך מנהל הקבצים של ימות): השרת חותך אותו אוטומטית בתוך כמה דקות ומוחק את המקור. קובץ ששמו `p0501234567_שם.mp3` נהפך לשיר אישי. קובץ שלא הצליח להיחתך (למשל קובץ שאינו שמע) נשאר בתקייה והשרת מנסה שוב כעבור שעה.

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `SONGS_EXT` | ריק (כבוי) | מספר שלוחת השירים |
| `SONGS_PASS` | ריק | סיסמה לדף `/songs` (בלעדיה הדף חסום) |
| `SONG_SEG_SEC` | 5 | אורך חלק בשניות |
| `HOLD_CHAIN` | 2 | כמה חלקים משמיעים בכל פעם |
| `SONG_MAX_MIN` | 6 | מקסימום דקות לשיר (המשך נחתך) |
| `INPUT_WAIT_SEC` | 7 | כמה שניות ממתינים לבחירה בתפריט (1 או 2) |

שימו לב: אחרי ההשמעה יש רווח קצר בין קבוצת חלקים אחת לבאה. לשיר שלם כ-3 דקות נוצרים כ-36 קבצים קטנים בשלוחה.


## השמעת קבצי שמע ווידאו מהאינטרנט

אפשר לבקש מהמערכת לנגן קובץ mp3, mp4 או כל קובץ שמע או וידאו אחר (נשמע רק הקול). מתקשר לא יכול להכתיב כתובת, ולכן הבעלים מגדיר מראש רשימת קבצים במשתנה `MEDIA_FILES`:

`[{"n":"שיעור יומי","u":"https://example.com/lesson.mp3"},{"n":"הקלטה שנייה","u":"https://example.com/clip.mp4"}]`

`n` הוא שם הקובץ (כך המודל מבין לאיזה קובץ מתכוונים) ו-`u` הוא קישור ישיר לקובץ עצמו, לא לדף אתר. אם יש רק קובץ אחד, מספיק לומר או להקליד "נגן את הקובץ". הקובץ מורד, מומר לפורמט של טלפון (ffmpeg) ומושמע מיד אחרי תשובה קצרה. הפעם הראשונה לוקחת כמה שניות, ואחר כך הקובץ נשמר בשלוחה וההשמעה מיידית.

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `MEDIA_MAX_MIN` | 20 | מקסימום דקות להשמעה (המשך הקובץ נחתך) |
| `MEDIA_MAX_MB` | 100 | מקסימום גודל קובץ להורדה |
| `MEDIA_PREP_MS` | 100000 | מקסימום זמן להכנת קובץ במילישניות |


## חיפוש שירים והשמעה

אפשר לומר או להקליד "חפש שירים חדשים" או "חפש שיר על אהבה", והמערכת מקריאה רשימה ממוספרת. אחר כך אומרים "נגן את מספר 2" והשיר מושמע אחרי משפט קצר. הרשימה נשמרת לאורך השיחה.

המקור הוא Jamendo, שירות מוזיקה חינמי עם API רשמי ושירים מלאים בהשמעה חוקית. נרשמים בחינם ב-developer.jamendo.com, יוצרים אפליקציה ומעתיקים את ה-client id למשתנה `JAMENDO_CLIENT_ID`. הקטלוג של Jamendo הוא מוזיקה של אמנים עצמאיים ולא להיטים מסחריים, והחיפוש עובד טוב יותר באנגלית. אפשר לבקש "השירים החדשים" ו"השירים הפופולריים השבוע".

בלי `JAMENDO_CLIENT_ID` המערכת משתמשת בחיפוש ברשת של Groq ובקישורים ישירים לקבצים, אבל זה פחות אמין (ראו את ההערה על קישורים ישירים בפסקה הקודמת).

האודיו מומר לפורמט טלפון (ffmpeg) ומועלה לשלוחה, כי ימות משמיעים רק קבצים שנמצאים אצלם.
